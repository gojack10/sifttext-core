Apply [[Nest Meaningful Developments|5caf4b24-85b9-46cc-88b5-50b80feb1c19]] to the proposed instruction structure.

Give each branch a meaningful responsibility with enough current instructions to perform it.

Identify the input it receives and the result it returns to its caller.

State what the agent must read before performing the action.

For a conditional read, state the condition that makes it necessary.

A return link continues the caller's work without restarting onboarding.

Ensure a required branch asks for the reading its task needs.

Reuse unchanged reads and batch independent inputs when supported.

Local Core can initialize a separate Git knowledge home, allocate private worktrees, create roots and children, validate complete authored candidates, normalize permitted status transitions, and submit checked Git edits. It generates version-consistent outlines, ranked lexical search and read-only SQLite retrieval. Use the local entrypoint and CLI Operations for exact commands and safeguards.

You or an authorized external agent edit scopes, bodies, names, warnings and explicit reference metadata with ordinary file tools in a private draft. Core checks supported structure and fields; it does not interview you, summarize, choose meaningful links, decompose your problem or judge whether an answer is true. Those tasks require human reasoning or a separately supplied model. A passing check is not semantic approval or proof of successful independent use.

Core needs no hosted account or model provider for normal knowledge work. Its native resource guards still apply; complete storage is not a promise of unlimited size or instant retrieval.

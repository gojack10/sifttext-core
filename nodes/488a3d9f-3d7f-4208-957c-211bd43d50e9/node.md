Push means supplying context before the agent chooses what to read.

Pull means letting the agent retrieve a relevant node on demand.

The current harness determines how context is supplied.

Place essential cautions near their instructions and identify required reads explicitly.

Keep optional background reachable through meaningful links so the current agent can choose additional detail.

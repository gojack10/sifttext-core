Use when user input materially changes the work.

Read [[Develop Understanding Through Interaction|31dc46ab-eaf1-4f1a-97ed-5ff88200c4d8]] and the contextual teaching examples before applying this method.

Recognize the contribution by explaining what it makes possible.

Use the grounds already supplied before asking for another explanation.

Ask a concise follow-up only when a consequential choice still lacks enough understanding.

An example or reversible attempt can help the user discover what they mean.

Accept a rough account without requiring a polished report or known destination node.

Attribute beliefs and interpretations faithfully while leaving unestablished claims open.

Stop the interview when the person declines or is unavailable, preserving the actual gap.

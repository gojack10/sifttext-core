## Tree-Native Skills

A skill is a repeatable workflow stored as a normal SiftText node. Instead of hiding procedure in a prompt file or one-off chat, the tree preserves when to use the workflow, how to execute it, what guardrails matter, and what a good output looks like.

Use a skill by reading its applicable instructions and following its explicit procedure. Before authoring or revising executable instruction nodes, apply the child named Canopy (Prompt Authoring Framework). Adaptation happens within stated discretion or a clarified human override; it is not permission to invent a missing workflow. The goal is reusable operational intelligence with an explicit default route and human control, not rigid project answers or an optional collection of suggestions. Improvements still follow SiftText Commit.

## Current state

Each skill owns its procedure and evidence boundary. Open direct child work keeps this hub open under the governing status rule.

A skill’s presence in the library does not establish that its runtime is installed, that it is automatically loaded, or that an agent successfully follows it. Qualification remains with the relevant skill and trial owners.

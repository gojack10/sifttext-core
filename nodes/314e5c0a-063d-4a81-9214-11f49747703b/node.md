## Apply the assignment
Recover the actual request and its authority before choosing a method.

Make ordinary investigation and drafting choices within that scope.

## Read before mutation
Read an affected existing owner before editing it.

Before creating a node, read its proposed parent and nearby possible owners.

Before moving a node, read both parents and the node itself.

Before adding a substantive reference, read both endpoints.

Preserve stable identities and other contributors' work.

## Communicate and save
Answer the user's actual question with enough context to assess the result.

Adapt the explanation to their familiarity and stated preferences.

Show the reasoning needed for a decision without dumping internal deliberation.

Use [[SiftText Commit|c72d552d-3499-445b-a8d5-05d0ff7824f2]] for knowledge changes and its approval boundary.

Additional user or project instructions retain their own scope.

Choose the current agent according to the task and the tools it can actually use.

Evaluate whether its reasoning is useful before entrusting it with more consequential decisions.

Account for provider costs and obtain permission before supplying sensitive knowledge to a hosted model.

Apply the same approved knowledge-publication procedure regardless of the selected model.

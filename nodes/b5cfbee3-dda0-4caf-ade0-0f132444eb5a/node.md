Claude Code must be installed and configured separately by the user. Core does not modify its settings or authenticate a provider. Follow the parent node's access and permission contract; confirm the actual harness can read the authorized home and run the verified Core command before asking it to execute work.

Start in the knowledge home and direct it to read the local AGENTS.md and the entrypoint's task-applicable selected methods. During authorized setup, use the parent's current Maintain Memory Continuity route rather than requiring a manual entrance reminder for every future chat. If the pointer is absent, provide the canonical entrypoint path as described by the parent. Give it a bounded task and explicit read/write permissions. No hosted SiftText MCP URL or OAuth setup is needed for local files.

Have the agent return source evidence or an authorized private draft and actual native check results. Missing paths, capabilities or permission stop dependent execution; preserve any draft. This is a setup recipe, not a qualified Claude Code behavior trial or permission to change client settings.

During authorized setup, use [Harness Bootstrap and Migration](../98892306-f87b-4361-9d91-fac2e0023a11/node.md) to make future conversations read the SiftText entrypoint.

Reuse a correct persistent pointer in later conversations.

For an authorized memory import, follow the migration branch without repeating completed setup.

When you find knowledge in another memory system that SiftText lacks, such as this harness's built-in memory, offer to import it. After the user approves, follow the migration branch for the sources they select. If they decline, do not offer again in this conversation.

Preserve existing instructions and recoverable memory sources.

Ask the user when the current harness supplies no persistent-instruction guidance.

Use a link to express a meaningful relationship without copying the target's answer.

An indexed link belongs in see_also as an actual target UUID with a nonblank reason.

A Markdown citation helps someone find the source while reading the body.

Parent-child symlinks define hierarchy, so avoid adding see_also edges that repeat a direct parent-child relationship.

Preserve useful findings beneath rejected approaches and connect them to continuing work when readers need that route.
